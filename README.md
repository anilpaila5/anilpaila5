### About Me

I'm **Anil Paila**, a **Senior SDET / QA Automation Engineer** with **9+ years** of experience designing and scaling test automation frameworks for web, API, and enterprise applications. I specialize in building reliable, maintainable automation suites using Java, Selenium, Playwright, Python, and REST Assured, and I wire them into CI/CD pipelines with Jenkins and GitHub Actions so teams can ship with confidence.

Outside of writing code, I enjoy breaking down complex QA and automation concepts into practical, easy-to-follow content. I create technical videos on **YouTube** and share automation tips on **Instagram**, helping fellow engineers level up their testing skills.

**A few fun facts about me:**
- 🧪 I've automated thousands of test cases across web and API layers over the years
- 🎥 I turn tricky automation problems into YouTube tutorials
- ☕ I probably run more test suites than cups of coffee I drink, and that's saying something
- 🚀 I love hunting down flaky tests and making them behave
